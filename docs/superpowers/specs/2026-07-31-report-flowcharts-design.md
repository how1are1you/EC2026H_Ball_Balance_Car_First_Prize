# 报告流程图设计说明

## 目标

依据当前固件代码制作两张适用于 A4 竖版报告的纯黑白标准图：

1. 滚球运动控制系统控制框图。
2. 主程序流程图。

图片同时提供 SVG 和 PNG。图中文字使用简体中文，白底黑线，不使用阴影、渐变或彩色装饰。

## 图一：滚球运动控制系统控制框图

采用自上而下的串级闭环结构，主通道为：

目标位置与参考速度 → 位置比较 → 位置 PI 外环 → 目标速度限幅与制动约束 → 速度比较 → 速度 PD 内环 → 加速度前馈叠加 → 舵机 PWM 限幅与量化 → 舵机及摆杆 → 滚球运动。

视觉模块测量滚球位置和速度，通过 UART1 帧解析、单位换算和低通滤波后，将位置反馈到外环，将速度反馈到内环。小车纵向加速度经过前馈系数和限幅后接入舵机控制量。

## 图二：主程序流程图

图的上半部分表示 `main()`：

上电 → SysConfig 外设初始化 → 控制模块初始化 → 中断清除与使能 → OLED 初始化 → MPU6050 初始化 → 初始化是否成功 → 成功时等待稳定 10 秒 → 进入主循环。

主循环依次执行 IMU 服务、控制串口服务、静态滚球任务服务、电池电压采样和 OLED 刷新，然后返回循环起点。

图的下半部分表示每 5 ms 触发的定时中断：

中断进入 → 更新时间及按键/LED → 编码器测速 → 运行模式变化判断与状态复位 → 滚球任务和滚球控制器更新 → 静态模式判断 → 停车标志判断 → 轨迹状态机 → 左右电机增量式 PI → PWM 限幅及电机输出 → 中断返回。

静态滚球模式和停车状态均直接输出零电机 PWM。轨迹状态机根据当前模式进入单圈循迹、转弯标定或直线圆弧组合控制。

## 版式约束

- 纸张方向：竖向。
- 图形方向：从上到下。
- 标准流程图形：起止椭圆、处理矩形、判断菱形、输入输出平行四边形、求和圆。
- 反馈线与前馈线均为黑色，使用不同虚实线型区分。
- 字号按插入 A4 正文后仍能辨认为准。
- 每张图底部保留规范图题位置，不把图题写入图片内部。
