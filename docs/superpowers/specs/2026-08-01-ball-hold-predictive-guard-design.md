# 小车运行期间小球预测保护设计

## 1. 目标

在 `RUN_MODE_BALL_HOLD_LAP` 中保持现有锁定位置不变，降低小车直线
启动和低概率转弯扰动造成的小球偏移，使小球相对锁定目标的最大绝对
偏差尽量不超过 `10 mm`。

本设计保留现有位置 PI、速度环、位置前馈、连续距离限速以及舵机输出
范围，只补充以下三项能力：

1. 保留并验证带实际运动门控的启动加速度前馈；
2. 将摄像头速度以低权重融合进状态观测器；
3. 仅在 `BALL HOLD` 模式增加无锁存的预测位置保护。

## 2. 非目标

- 不计算或补偿转弯向心加速度；
- 不修改小车直线、弯道和停车轨迹；
- 不在第一版中根据小球位置降低车速；
- 不修改 `BALL STATIC` 的 `0 -> +50 mm` 和 `-50 -> +50 mm`
  定点控制行为；
- 不增加位置 D、额外积分器、制动锁存、爬行阶段或最低接近速度；
- 不改变舵机 `500 us` 至 `2200 us` 输出范围和 `5 us` 量化；
- 不提交或暂存任何文件。

## 3. 现状与问题

### 3.1 `10 mm` 当前只是验收阈值

`ball_hold_lap_update_measurement()` 只在绝对误差超过 `10 mm` 时将
`ball_hold_lap_position_pass` 锁存为失败，不会改变小球控制量。因此它
不是主动保护边界。

### 3.2 启动前馈已有静摩擦门控

`startup_motion_gate` 要求左右编码器平均速度超过 `0.02 m/s`，并连续
两个 `5 ms` 控制周期满足条件，才允许
`StraightTurnStartupAccelerationMps2` 非零。

因此车轮未克服静摩擦、编码器尚未确认运动时，加速度前馈必须继续保持
为零。第一版不降低该门槛，也不增加运动前的舵机预加载。

### 3.3 摄像头速度只用于观测器初始化

观测器初始化后主要依靠位置残差修正速度，没有继续融合摄像头发送的
帧间差分速度。突发扰动开始后，速度估计可能落后于小球真实运动趋势。

### 3.4 当前距离限速不能形成 `10 mm` 保护

当前 `BALL_BALANCE_DISTANCE_PROFILE_ACCEL_MM_S2=70`。在位置误差
`10 mm`、位置积分近似为零时，位置 P 目标速度约为 `20 mm/s`，而
距离速度上限约为 `33.5 mm/s`，所以距离限速不会介入。它适合大距离
定点运动，不适合作为 `BALL HOLD` 的小偏差安全边界。

## 4. 总体数据流

```text
摄像头位置、速度
        |
        v
位置残差速度估计 + 摄像头速度低权重融合
        |
        +-------------------------------+
        |                               |
        v                               v
现有位置 PI -> 连续距离限速       预测未来位置误差
        |                               |
        +----------选择更强的回中速度---+
                        |
                        v
                现有速度环和加速度阻尼
                        |
                        + 启动运动门控后的车辆加速度前馈
                        |
                        v
                     舵机输出
```

预测保护只改变进入速度环的目标速度，不直接操作舵机脉宽。

## 5. 启动运动门控前馈

保留当前 `startup_motion_gate` 行为：

```text
encoder_average_speed <= 0.02 m/s
    -> vehicle_acceleration_feedforward = 0

连续两个周期 encoder_average_speed > 0.02 m/s
    -> 允许使用启动指令加速度前馈
```

第一版不修改门槛和确认周期。新增或保留可观测量，以便上板确认：

- 运动门控是否已经打开；
- 当前启动指令加速度；
- 最终车辆加速度前馈脉宽；
- 门控打开时的小球位置和速度。

如果硬件数据证明门控明显晚于车体开始运动，再将门槛调整作为独立任务，
一次只改变一个参数。

## 6. 摄像头速度融合

### 6.1 融合公式

只在收到新视觉帧时执行速度融合：

```text
v_residual =
    observer_velocity
    + beta * position_residual / frame_dt

v_fused =
    (1 - camera_velocity_blend) * v_residual
    + camera_velocity_blend * camera_velocity
```

初始参数：

```text
camera_velocity_blend = 0.25
```

位置残差估计仍占 `75%`，摄像头差分速度只提供更及时的方向和趋势。
所有输入继续使用现有有限值校验和 `+/-500 mm/s` 限幅。

### 6.2 更新与失效

- 同一视觉帧不得重复融合；
- 无新帧时沿用现有 `5 ms` 位置预测；
- 视觉数据失效时沿用现有观测器失效处理，不保留旧速度；
- 第一版保留现有加速度滤波结构，避免同时改变速度融合、加速度估计和
  速度环阻尼三个变量；
- 如果上板记录显示融合后的速度跳变导致加速度阻尼脉冲，再单独把加速度
  改为按实际视觉帧间隔计算。

## 7. `BALL HOLD` 预测保护

### 7.1 启用范围

预测保护只能由 `RUN_MODE_BALL_HOLD_LAP` 启用。控制器本身不直接依赖
`Run_Mode`，而是通过明确的启用接口接收状态。

离开 `BALL HOLD`、控制器禁用、视觉失效或 PID 复位时，预测保护状态和
诊断量全部清零。静态定点模式始终禁用预测保护。

### 7.2 预测误差

控制器内部使用与位置 PI 一致的误差方向：

```text
position_error = target_position - estimated_position

predicted_error =
    position_error
    - estimated_velocity * prediction_time
```

初始参数：

```text
prediction_time = 0.060 s
soft_boundary = 5.0 mm
acceptance_boundary = 10.0 mm
```

状态观测器已经按 `5 ms` 周期将位置预测到当前控制时刻，因此
`prediction_time` 只表示尚未体现的视觉流水线延迟和舵机机械响应，不再
重复叠加视觉帧龄。

### 7.3 连续保护速度

当预测绝对误差超过软边界时，计算回中速度要求：

```text
excess =
    max(abs(predicted_error) - soft_boundary, 0)

guard_velocity_magnitude =
    clamp(guard_gain * excess, 0, guard_velocity_max)

guard_velocity =
    sign(predicted_error) * guard_velocity_magnitude
```

初始参数：

```text
guard_gain = 8.0 /s
guard_velocity_max = 60.0 mm/s
```

示例：

```text
当前位置相对目标偏差 = +6 mm
小球速度             = +50 mm/s
prediction_time       = 0.060 s

未来位置偏差 = +9 mm
保护回中速度幅值 = (9 - 5) * 8 = 32 mm/s
```

### 7.4 与位置 PI 的合并

先完成现有位置 PI 和连续距离限速，再比较普通目标速度与保护速度。

- 如果普通目标速度已经沿预测误差方向提供了相同或更强的回中速度，
  保留普通目标速度；
- 如果普通目标速度方向错误或回中速度不足，使用保护速度；
- 保护只会增强回中，不会削弱已经更强的 PI 控制；
- 保护覆盖目标速度时冻结本周期的位置积分候选；
- 不使用进入锁存、退出锁存、迟滞状态机或最低速度。

随着小球减速或开始返回，`predicted_error` 和 `excess` 连续减小，保护
速度自然退出。

## 8. 接口和诊断

控制器增加明确的预测保护启用接口，`BALL HOLD` 状态机负责调用，其他
模式保持禁用。

建议公开以下只读诊断量：

```text
ball_balance_predicted_error_mm
ball_balance_guard_velocity_mm_s
ball_balance_guard_active
ball_state_observer_camera_velocity_mm_s
ball_state_observer_velocity_blend_active
```

诊断量用于主机测试、调试器和上板记录，不参与状态机判定。

## 9. 测试

### 9.1 主机测试

观测器测试覆盖：

- 初始化仍接受摄像头位置和速度；
- 新帧按 `0.25` 权重融合摄像头速度；
- 相同帧不会重复融合；
- 正负速度对称；
- 非有限值和失效视觉不会污染状态。

控制器测试覆盖：

- 预测误差不超过 `5 mm` 时完全保留原 PI；
- 小球快速远离目标时，预测保护在实际误差小于 `10 mm` 时提前介入；
- 小球已经返回且 PI 更强时不覆盖 PI；
- 正负方向对称；
- 保护覆盖时冻结位置积分；
- 预测保护禁用时现有静态定点结果不变；
- 视觉失效、模式退出和 PID 复位清除保护状态。

随后重新编译并执行全部八个主机测试，并强制执行 Keil 重建。

### 9.2 上板验收

至少重复五次完整 `BALL HOLD` 运行，分别记录：

- 启动门控打开时间；
- 门控打开时的小球位置与速度；
- 摄像头速度、融合速度；
- 当前误差、预测误差；
- 普通 PI 目标速度、保护速度、最终目标速度；
- 加速度前馈脉宽和最终舵机脉宽；
- 直线启动阶段最大绝对误差；
- 两个弯道各自最大绝对误差；
- 是否出现反向回退或连续往返。

第一版验收目标：

- 静态定点控制行为无回归；
- 启动静摩擦阶段不产生车辆加速度前馈；
- 预测保护不产生停住再启动；
- `BALL HOLD` 最大绝对位置误差尽量不超过 `10 mm`。

若仍偶发超过 `10 mm`，优先依据记录判断是启动门控过晚、速度融合滞后
还是舵机能力不足，不同时修改多个增益。只有上述三项已经正确工作仍无法
满足约束时，才进入第二阶段的小车加速度限制设计。
