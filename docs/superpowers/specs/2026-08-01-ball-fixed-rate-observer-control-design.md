# 小球固定周期观测与控制设计

## 目标

将现有小球控制从“视觉新帧到达时才执行”改为固定 5 ms 执行：

- 视觉串口只发布测量和新帧标志，不直接决定控制器何时运行。
- α-β 观测器在每个 5 ms 周期预测小球位置和速度；新视觉帧只用于校正观测状态。
- 速度内环的 D 项改为对测量速度微分，即使用估计加速度产生阻尼：
  `u_d = -Kd * a_estimated`。
- 保留现有位置 PI、速度 P、车辆加速度前馈、限幅、抗积分饱和和视觉失效保护。

预期改善是降低视觉帧率和到帧抖动造成的控制阶梯与相位滞后，消除目标速度变化引起的微分冲击，并减小端点过冲和舵机抖动。

## 当前行为与问题

硬件定时器已经每 5 ms 触发一次，`TIMER_0_INST_IRQHandler()` 也会在每次中断调用 `ball_balance_update()`。但 `ball_balance_update()` 检测到视觉帧计数未变化时会直接返回，因此有效控制频率仍等于视觉帧率。

视觉接收层当前先低通位置，再用相邻滤波位置计算速度；控制层随后又对该速度低通。重复滤波增加相位滞后。当前 D 项计算速度误差的差分：

```text
d(v_target - v_measured) / dt
```

所以位置外环导致 `v_target` 变化时，D 项也会产生突变。静态模式切换目标以及移动模式更新参考速度时，都可能出现明显的舵机冲击。

舵机 PWM 周期为 20 ms。固定 5 ms 控制不会把舵机物理刷新率变为 200 Hz，但能保证每个 PWM 周期采用最新的估计状态和控制指令。

## 方案比较

### 方案 A：保留新帧驱动控制

改动最少，但控制周期继续受视觉帧率和串口抖动影响，不能解决帧间状态冻结和微分冲击，不采用。

### 方案 B：α-β 观测器加滤波加速度

位置、速度由 α-β 观测器估计；每 5 ms 预测，新帧到达时按残差校正。估计速度再经固定周期带限微分得到加速度，供测量微分 D 项使用。

该方案计算量小、适合 Cortex-M0+，不需要建立完整滚球模型，且能满足当前目标，作为本次实现方案。

### 方案 C：α-β-γ 或卡尔曼观测器

直接把加速度作为状态，动态表现可能优于方案 B，但需要更多模型假设和参数辨识。当前视觉帧率、链路延迟、舵机—平台—钢球模型尚未量化，本次不引入；若方案 B 的加速度质量不足，再单独升级。

## 模块边界

### `Control/ball_state_observer.c/.h`

新增独立观测器模块，负责：

- 保存估计位置、估计速度和滤波加速度；
- 每 5 ms 执行一次状态预测；
- 检测并消费视觉新帧，对状态进行一次校正；
- 处理首次初始化、视觉超时、复位、速度和加速度限幅；
- 提供一致的只读状态快照给控制器和任务状态机。

观测器不直接设置舵机，不保存 PID 参数，也不决定任务模式。

### `Control/uart_callback.c/.h`

串口层只负责：

- 解析并校验视觉协议中的 `float32` 位置和速度；
- 统一换算成 mm、mm/s；
- 发布原始测量、接收时刻、有效标志和递增帧计数；
- 继续统计协议和 UART 错误。

移除串口层的位置低通、位置差分速度和相关滤波状态。视觉速度只用于观测器首次初始化和诊断；正常运行期间，α-β 校正以视觉位置测量为主，避免同时混用两个来源不一致的速度估计。

UART 中断写完全部测量字段后最后递增帧计数。5 ms 控制侧继续使用“前后两次读取帧计数一致”的方式获得原子快照。

### `Control/ball_balance.c/.h`

控制器负责：

- 每 5 ms 读取观测器状态并执行一次完整控制计算；
- 使用固定 `dt = 0.005 s` 更新位置积分；
- 保留现有位置 PI、目标速度限幅、制动速度限制和抗积分饱和；
- 使用估计速度计算速度误差；
- 使用估计加速度计算 D 阻尼；
- 保留车辆加速度前馈、舵机输出限幅和 10 us 量化；
- 暴露估计位置、速度、加速度和各控制分量，便于 OLED/串口调试。

删除“视觉帧计数未变化就返回”的控制门控，以及上一速度误差和变动采样周期相关状态。

### 小球任务状态机

`ball_static_task` 和 `ball_hold_lap` 的稳定判断、当前误差和速度阈值改用同一份观测器位置、速度快照。视觉新鲜度判断仍以最后一帧接收时间为准，避免控制器和任务状态机使用不同状态来源。

### `Control/control.c`

每个 5 ms 中断的顺序固定为：

1. 更新时间和采集基础传感器；
2. 更新小球观测器，先预测，若有新帧再校正；
3. 更新小球任务状态机和参考值；
4. 更新小球控制器；
5. 更新车辆控制和执行器。

观测器只更新一次，所有消费者读取同一周期的状态。

## 观测器算法

固定控制周期：

```text
Ts = 0.005 s
```

每个控制周期先预测：

```text
x_predict = x_est + v_est * Ts
v_predict = v_est
```

没有新视觉帧时：

```text
x_est = x_predict
v_est = v_predict
```

收到新位置测量 `z_position` 时，以自上一视觉校正以来的实际时间 `Tvision` 计算残差：

```text
residual = z_position - x_predict
x_est = x_predict + alpha * residual
v_est = v_predict + beta * residual / Tvision
```

`Tvision` 由相邻有效帧接收时间计算并限制在 5～200 ms；首次有效帧直接令 `x_est` 等于视觉位置，并用经过范围限制的视觉速度初始化 `v_est`。不对同一帧重复校正。

初始保守参数：

```text
alpha = 0.55
beta = 0.10
|v_est| <= 500 mm/s
```

这些参数作为可调宏和串口调参候选，初次上板时先保持固定，只在采集观测误差日志后调整。

## 加速度估计

α-β 观测器采用恒速度模型，不直接产生连续加速度状态。每个固定周期对校正后的估计速度进行带限微分：

```text
a_raw = (v_est - v_est_previous) / Ts
a_est = a_est + accel_alpha * (a_raw - a_est)
```

初始参数和保护：

```text
accel_alpha = 0.20
|a_raw| <= 3000 mm/s^2
|a_est| <= 2000 mm/s^2
```

先限幅 `a_raw`，再低通并限制 `a_est`。这样视觉校正造成的速度阶跃不会直接成为 D 项尖峰。观测器首次初始化、关闭、视觉超时或 PID 复位时，将 `a_raw`、`a_est` 和上一速度同时清零，避免重新启用时产生假加速度。

## 控制律

外环保持位置 PI：

```text
position_error = position_target - x_est
v_target =
    reference_velocity
    + position_kp * position_error
    + position_ki * position_integral
```

继续执行位置死区、积分限幅、抗积分饱和、目标速度限幅和静止目标下的制动速度限制。

内环改为：

```text
velocity_error = v_target - v_est
u_p = velocity_kp * velocity_error
u_d = -velocity_kd * a_est
u = u_p + u_d + vehicle_acceleration_feedforward
```

符号约定沿用当前 `BALL_BALANCE_SERVO_DIRECTION`。本次不增加目标加速度微分或目标加速度前馈，因此目标改变不会直接进入 D 项。现有车辆加速度前馈保持不变，它补偿车辆运动对钢球的扰动，不等同于目标速度微分。

由于 D 项定义发生变化，现有 `velocity_kd = 0.12` 仅作为首次低速试验起点，必须重新调参，不能以旧控制器的效果作为其有效性依据。

## 视觉失效与边界处理

- 尚未收到有效视觉帧：观测器无效，控制器保持等待并输出中位。
- 视觉年龄不超过现有 200 ms 超时：继续按 5 ms 预测和控制，但位置、速度、加速度均受限幅保护。
- 视觉年龄超过 200 ms：状态标记为过期，控制器清除积分与观测动态状态，舵机回中位。
- 视觉位置或速度为 NaN、无穷或超出允许物理范围：丢弃整帧并增加错误计数，不校正观测器。
- 帧计数跳变超过 1：只消费最新完整帧，不补做多次校正。
- 32 位毫秒计数差值继续使用无符号减法，允许自然回绕。

当前协议没有视觉拍摄时刻，只能以完整帧接收时刻作为测量时刻。本次不修改串口协议，也不补偿相机曝光和图像处理延迟；若实测固定延迟明显，再为协议增加采集时间戳并单独设计延迟补偿。

## 调参顺序

1. 令 `Ki = 0`、`Kd = 0`，低速验证位置和速度符号、观测器预测方向及失效保护。
2. 固定控制器参数，记录原始位置、残差、估计位置和估计速度；先调 `alpha`，再调 `beta`。
3. 检查 `a_raw` 和 `a_est`，调整 `accel_alpha`，确保稳态噪声不会驱动舵机跨越 10 us 有效步进。
4. 调速度 `Kp`，获得不过度振荡的基础响应。
5. 从较小 `Kd` 开始增加测量加速度阻尼，观察端点过冲和舵机峰值。
6. 最后恢复并微调位置 `Ki`，只用于消除静差。
7. 分别验证静态正负目标切换、原地保持、车辆启动加速和完整绕行。

每次只改变一组参数，并保留相同工况的串口日志用于对比。

## 验证与完成标准

### 软件验证

- Keil `MSPM0G3507_Project` 完整构建通过且无新增警告。
- 观测器和控制更新计数在稳定运行时均为每秒 200 次。
- 视觉帧间且 `v_est != 0` 时，`x_est` 每 5 ms 连续变化。
- 同一视觉帧只校正一次，未到新帧时只执行预测。
- 改变位置目标但小球状态未变化时，`u_d` 不产生目标微分冲击。
- 视觉数据停止超过 200 ms 后，状态进入过期且舵机回中位。
- 加速度、目标速度、积分和舵机输出限幅均可通过边界输入验证。

### 上板验证

- `BALL_STATIC`：完成现有正、负端目标与稳定判据，比较修改前后的最大位置误差、端点过冲、稳定时间和舵机峰值变化。
- `BALL_HOLD`：车辆静止、启动加速、匀速和制动阶段均无持续发散，视觉短帧间隔内控制输出连续。
- 短时遮挡：在未超过 200 ms 时预测保持有界；超过超时后立即回中位，不继续外推。
- 记录所用板卡、视觉帧率、固件模式、PID/观测器参数和串口或 OLED 现象。
