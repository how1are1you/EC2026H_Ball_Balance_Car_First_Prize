# IMU 加速度 OLED 调试显示设计

## 目标

在现有 `IMU DEBUG` 模式中显示 MPU6050 的三轴原始加速度，供手推小车时直接观察前进方向对应的 IMU 轴及其正负号。此项调试用于后续设计小球平衡的实际加速度前馈。

## 范围

- 仅扩展 `IMU DEBUG` 的 OLED 页面。
- 显示 `AX`、`AY`、`AZ` 三个原始加速度值，单位为 `g`。
- 保留现有 IMU 状态、航向角和 Z 轴角速度显示。
- `IMU DEBUG` 模式保持车辆停机。

不新增串口输出，不做静止基线标定、峰值保持、方向自动判定或重力补偿；不改变 IMU 驱动、控制器、视觉串口和小球平衡前馈。

## 实现边界

`Hardware/imu/imu.c` 已将 DMP FIFO 的原始三轴加速度发布到 `imu_sample_t.accel_g[3]`。`Control/show.c` 的 `imu_debug_oled_show()` 读取同一 IMU 快照，并将三轴数值显示到 OLED。

为适配现有 128x64 OLED，调试页显示 IMU 状态、航向角、Z 轴角速度，以及三轴加速度。显示值保留足够的小数位，以便辨别静止时约 1 g 的重力轴与手推时变化最大的轴。

## 使用与验收

1. 进入 `IMU DEBUG`，确认车辆停止并等待 IMU 状态为 `READY`。
2. 保持车辆静止，记录三个加速度读数；竖直轴通常接近 +/-1 g。
3. 沿车辆前进方向快速推一次，再沿反方向推一次。
4. 确认同一加速度轴变化最明显且正负号相反；记录该轴与前进方向的对应关系。
5. Keil 目标 `MSPM0G3507_Project` 全量构建成功，且无新警告。
